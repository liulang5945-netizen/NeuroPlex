## 1. 执行摘要

**总体结论**：这是一个真实、高强度的个人研究项目。checkpoint 真实可加载（73 个 state keys 实测）、训练日志链完整、pytest 16/16 可复现、对历史事故（因果掩码、seed bug、数据重复、口径漂移）的记录坦诚。项目自评"架构就绪、待训练验证"基本准确。

**但存在三类系统性缺陷**：

1. **共振机制的学习核心大部分未被训练**——推理评分被 4096×4096 随机矩阵（W_cond）门控，round 2+ 条件化由随机初始化的 field_read_layers 完成，训练与推理的评分口径不一致；
2. **实验证据方法学不可靠**——A/B 结论 48 小时内反转三次、坏结果后修改评估口径、验证脚本存在恒真式断言、"非空即通过"、plan 声称的阈值（4/4）与代码阈值（≥1）不符；
3. **多个"已闭环"功能在生产路径上是断的**——记忆固化零生产调用者、STDP 在默认 continuous 路径休眠、sparse_router 训练产物从不加载、多个 bio 模块是死开关。

**结论分级**：项目作为**实验笔记本**价值很高（诚实记录事故与失败）；但最近一个月（C25-E、C26）的里程碑声明的证据强度被系统性高估，需降级为"当前评估口径下观察到，未达可复现证据标准"。

## 3. 架构真实性

### 3.1 生成管线：真实且重度迭代 ✅

- `Cortex.generate()`（cortex.py:944-1034）是完整的 P7 管线：tokenizer hub、领域路由（`_executive_route` cortex.py:1294-1333）、judge-NLL 判定、共振（离散 `forward` / 默认连续 `continuous_forward`）、采样解码（温度/重复惩罚/无重复 ngram/EOS 偏置/熵停/CJK 截断/域词表回填）。
- 生产调用者真实存在：`api/routes_taiji.py:485-521`（cortex_chat）、`taiji/body/senses.py:128-132`。
- 训练产物真实：5 个 dialogue neuron checkpoint（2.0-2.8GB，可 torch.load）、67.42 有完整日志链（std0 best val PPL @ step 8000）。

### 3.2 共振场语义：学习过的写入 × 固定累加规则 × 未训练的读/评分门控 ⚠️

场本身是"L2 归一化 → 乘 scale → 累加"的确定性累加器（field.py:97-139）。学习全部发生在进出场的投影上，但 5 条学习通道中 **至少 3 条在推理时是随机/未训练的**：

| 通道 | 位置 | 训练状态 | 证据 |
|---|---|---|---|
| field_write / heads / gate / queries | neuron.py:702-897 | ✅ 是 | 三个训练脚本解冻（train_cross_domain_collab.py:473-474 等） |
| side_channels (excite/inhibit) | neuron.py:276-700 | ✅ 是 | 三个训练脚本全部解冻 |
| quality_head | neuron.py:190-200 | ✅ 是 | train_cross_domain_collab.py:458-461 等 |
| cross_spec 投影层 | ensemble.py:420-435 | ✅ 是 | train_cross_domain_collab.py:494-499 |
| **W_cond 门控** | field.py:67, 362-398 | ❌ **否** | 全仓库仅 field.py + ensemble.py:506-513 引用；collab ckpt 不存场权重（train_cross_domain_collab.py:264-288） |
| **field_read_layers** | neuron.py:203-206, 618-649 | ❌ **否** | 所有训练脚本均不解冻 |
| **field_score_proj** | ensemble.py:442-450 | ❌ **否** | score_dim 默认 None（config.py:98）；代码自认"从未启用"（ensemble.py:2841） |

### 3.3 关键缺陷清单（按严重度）

1. **`[已验证]` W_cond 随机门控推理评分**：field.py:67 `nn.Parameter(torch.randn(dim, dim) * 0.02)`（4096×4096 ≈ 16.7M 参数）。`_condition`（field.py:362-381）以 `sigmoid(state @ W_cond)` 门控场状态后参与每轮 `score()`（field.py:383-398）→ 融合权重。无任何训练路径，ckpt 不保存 → **每次运行都是新随机数**。注释（field.py:46-48）声称"H8 fix：已在使用"——"被使用"≠"被训练"。
2. **`[已验证]` 训练-推理评分口径不一致**：`forward_train` 完全不使用 `self.field`（ensemble.py:2172 自述），评分 = 裸 cosine（2511-2514）；推理 `field.score()` = W_cond 门控 cosine。同一"共振分"在训练与推理语义不同。
3. **`[已验证]` field_read_layers 随机条件化**：round 2+ 每层 `field_read_layers[i](field_state)`（neuron.py:620）恒为随机初始化；训练脚本只解冻尾层+norm+lm_head+field_write（train_cross_domain_collab.py:440-478、finetune_side_channels.py:348-363、finetune_cross_spec.py:434-449）。
4. **`[交叉核验]` shared_weight_mlp 读错场**：ensemble.py:1733 `self._field.get_state()` 取默认场；多线程推理时任务场在 thread-local（`_get_task_field`，ensemble.py:503+），per-sample 权重与真实任务无关。且该 MLP 从未训练。
5. **`[交叉核验]` sparse_router 训练产物丢失**：训练侧保存（train_cross_domain_collab.py:279-280、finetune_cross_spec.py:129-130），生产 loader 的 `_load_collab_weights_into_cortex` 不处理 `sparse_router_state`（loader.py:975-1117），生产 ensemble 默认不创建 router。
6. **`[交叉核验]` fieldcond 孤儿路径**：cortex.py:191-195 优先加载 `neuron_{domain}_fieldcond.pt`，但全仓库无任何写入该文件的代码 → 实际恒回退 base ckpt，分支为死逻辑。
7. **`[交叉核验]` field.reset() 破坏 register_buffer 语义**：field.py:60-63 注册 buffer，77-91 重新赋值普通张量 → `.state_dict()` 序列化的是旧 buffer。推理中途还直接手改 `self.field.state = self.field.state - old_contrib`（ensemble.py:1480-1486）。
8. **`[交叉核验]` 设备全链路假设 CPU**：field 构造不传 device（cortex.py:87 → field.py:58 默认 cpu）；neuron `.to(self.device)`（cortex.py:206 等）。若 device="cuda" 则 `field.write` 的 `state + v_scaled` 必崩。当前全部脚本默认 cpu，属潜伏缺陷。
9. **`[交叉核验]` `_phase_loss` 初始化设备错配**：ensemble.py:341 CPU 叶子张量，仅 gamma 可微路径才替换（2548-2550），GPU 训练时进 loss 求和会设备不匹配。

## 4. 科学严谨性（实验证据方法学）

1. **`[已验证]` A/B 结论 48 小时内反转三次**：10:2 → 2:7 → 3:4:5（日志原始数字与提交历史吻合）。无种子、无显著性检验、阈值事后标定（verify_zh_leader_ab.py L147/161-169）。最新 plan 甚至把方向写反——日志是 B:A=7:2（A 在输），plan 写"从 7:2 收敛到 3:4:5"。
2. **`[已验证]` 坏结果后修改口径**：commit 380a356 将培养期 PPL 评估集从提问式改为同分布列表式，同一实验结论从"降 33%"变为"降 79%"（提交信息自述两个数字）。这是仓库最高危模式：**评估定义在观察到结果后变更**。
3. **`[已验证]` 恒真式断言**：verify_c25_e_collab_ab.py:83 `dom_con[tag] = d1`——"判定一致性"检查是赋值构造，恒真。实际唯一实质断言是 5 个已知 prompt 的域分类期望。
4. **`[已验证]` plan 声称与代码阈值不符**：e21cb19 提交信息与 plan 声称"leader logits 改变 4/4（硬）""向量通道 4/4""文本通道 4/4"，但代码阈值为 `logit_ok >= 1`（verify_c26_memory_read_gen.py:231）、`vec_changed >= 1`（252）、`txt_changed >= 1`（254）——**1/4 即通过**。
5. **`[已验证]` "10/10 PASS"无落盘日志**：verify_c26_memory_read_gen 的结果仅存在于提交信息；仓库其他回归均有 Tee-Object 捕获日志。
6. **`[已验证]` 质量检查 = 非空字符串**：`regress_c25e_collab_ab_20260814.log:64-80` 显示 math/en 输出为无意义串仍 "20/20 PASS"；test_api_dialogue.py 无任何断言，其日志显示 Q2"无法、、、、。"、Q4"1 + "、Q5"1.<0x0A>" 仍被 plan 记为"8 问全部正常"。
7. **`[交叉核验]` 评测基准弱**：67.42 为同分布 100 条 held-out；"降 27-30%"跨 48K/167K 两个不同数据池，不可比；WriteGate"优于硬阈值"为训练分布内评测。
8. **`[交叉核验]` 测试不覆盖真实模型**：16 个 pytest 全部用随机权重或纯函数，无一加载真实 checkpoint；`tests/architecture_verification.py` 引用不存在的目录（`resonance_neurons_joint/`、`taiji_data/training_data/pretrain_mix_v1`）。

## 6. 工程质量

- **ResonanceEnsemble 不是 nn.Module**（ensemble.py:40）：内嵌 cross_spec_projectors、field_score_proj、shared_weight_mlp、sparse_router 不在任何 Module 层级 → `.to()/.eval()/.state_dict()` 不传播，全靠手工管理（已造成 device、buffer 两处实锤缺陷）。
- **静默吞异常**：6+ 处 `except Exception: pass`（ensemble.py:1247-1250、1256-1260、1467-1471、1380-1393、2168-2169、2222-2223），lateral inhibition、WTA、记忆写场、Kuramoto 演化失败全部无声。
- **超长函数**：forward 718 行（1052-1769）、forward_train 883 行（2013-2895）、continuous_forward 240 行（1773-2012）、_parallel_forward 146 行。
- **魔法数字无配置源**：GATE_FACTOR=50.0、QUALITY_ACTUAL_TEMP=1.0、NLL_EMA_ALPHA=0.05、loss 系数 0.01/0.05/0.5、W_cond std=0.02、init_scale=50.0——靠中文注释记录历史。
- **硬编码路径**：`checkpoint-481000`（loader.py:59,65 相对；scripts/data_prep/download_sft_data.py:63、fill_missing_domains.py:36、fill_general_domain.py:40 为绝对 `E:/taiji-neuron/...`）；README.md:175 过时 `checkpoint-400000`；collab ckpt 名与数据目录深度耦合（taiji/core/model_loader.py:71、train_field_memory_components.py:36-37）；对话综合体 ID 硬编码（train_field_memory_components.py:34-35）。
- **文档漂移**：README/CODE_WIKI 声称 P0"统一 field_dim=4096"，实际 COMPACT=2048（config.py:192）/STANDARD=3072（202）/FOUNDATION=4096（214）/EXPERT=4096（225）；共享嵌入 512-dim 一致无冲突（2048 仅出现在教师 hidden 投影源与 COMPACT field_dim）。
- **仓库卫生**：`.local/`、`.npm-cache/`、`.npm-global/`（~1GB）未入 .gitignore；requirements.txt 与 pyproject.toml 依赖不一致（pyproject 缺 tiktoken/starlette/langchain-experimental/scipy/bitsandbytes/PyQt6/pytest）；354 个提交从未推送、无外部审查；field_memory.py 存在未提交的"增量三"与已提交状态混杂。
