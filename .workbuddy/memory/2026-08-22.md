## 项目全面分析（taiji-neuron）
- 完成 7 维度全项目分析，报告输出至 `E:\taiji-neuron\PROJECT_ANALYSIS.md`。
- 关键结论：仓库为双轨结构——活跃研究方向 `taiji/`+`seed/`（原生预测基底，替代 Transformer，局部学习无反向传播，checkpoint 格式 taiji-native-v6）；产品轨道（api/ + frontend/ + desktop/）实际全部委托冻结的 `neuroplex/` 九成员 Transformer 基线，尚未迁移到原生基底。
- 技术栈：Python/PyTorch(仅张量引擎) + FastAPI(SSE+WS) + Vue3/Vite/Pinia/NaiveUI + PyQt6/WebEngine + PyInstaller/NSIS。CI 在 GitHub Actions。
- 重要发现（P0）：neuroplex/services/auth_service.py 是空 stub，登录链路损坏；auth 默认关闭且 /assets、/workspace_data、/ws/ 永久公开；/api/workspace/run、tools/execute、/ws/terminal、热更新端点构成任意代码执行面，仅靠 127.0.0.1 缓解。
- 性能债：SparseSynapses 初始化 O(out×in) 峰值；单 tick 无批处理、大量 .item() 同步。
- 工程债：desktop/main.py 与 api/run_app.py 双入口未合并；build.py 与 seed.spec 打包配置不一致；端口 8000/8765 硬编码散落多处；多处 return HTTPException 而非 raise。
